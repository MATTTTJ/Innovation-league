# 혁신기업 키움 리그

조달청 공모전 출품용 HTML5 웹게임 프로토타입입니다. 지원서만 보고 고른 혁신기업을 조달 카드로 키워 분기 순위전에서 살아남게 하는 경영 시뮬레이션입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 인터넷 연결이 필요 없습니다.

- 조작: 마우스, 또는 Enter·Space·방향키·숫자키
- H: 도움말 · I: 기업 자세히 보기 · M: 소리 켜기/끄기
- 밸런스 값은 모두 `config.js`에 있습니다.
